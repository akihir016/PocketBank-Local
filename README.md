# PocketBank AI V2

This is a local version of the PocketBank AI app with a new chat feature that allows users to chat with each other.

## Run Locally

**Prerequisites:**  Node.js

### 1. Run the Frontend

1. Open a terminal in the root directory.
2. Install dependencies:
   `npm install`
3. Run the app:
   `npm run dev`

The frontend will be running on `http://localhost:5173`.

### 2. Run the Backend

1. Open a second terminal in the `server` directory.
2. Install dependencies:
   `npm install`
3. Run the server:
   `npm start`

The backend server will be running on `http://localhost:3001`.

Now you can open multiple instances of the application in your browser and start chatting!
